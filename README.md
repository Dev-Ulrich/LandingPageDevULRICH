# DevUlrich

Landing page em React, TypeScript e Vite. Combina o hero do protótipo HTML com navegação responsiva, portfólio real, serviços, apresentação profissional e alternância de tema.

## Rodar localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.

Os projetos e links estão em `src/data.ts`. A logo original está em `public/logo-devulrich.png`. Valores são referências dos projetos de origem e devem ser revisados antes da publicação comercial.

As imagens exibidas usam versões WebP em `public/images`. Os PNGs originais foram preservados em `public`. As galerias carregam prévias responsivas e usam a imagem maior na visualização ampliada.
